# Hearths — Raid Giant Dungeon Towers Across the Nether

Hearths 9minecraft Mod fills the Nether dimension with giant dungeon towers and rich landscape decorations. It places tall spires in the crimson and warped forests for players to climb. Inside these towers, you run into dangerous hazards like blaze rooms and search for hidden loot chests. The mod also decorates the terrain with rock pillars, fungi clusters, and small lava pools. You encounter these new locations naturally as you generate new chunks in the Nether.

## What this build is

An unofficial rebuild of **bebebea_loste**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
